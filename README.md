# Termixel

**This project was not written by a clanker**

Termixel is a minimal and sort of fast terminal sprite renderer. It utilizes unicode characters to render pixelart in the
terminal. Termixel is heavily optimized for size and comes at around 200KB currently also it doesnt support any other format then .png currently and will propably never do
if you want support for more file formts feel free to fork the repo and implement it yourself.

> The project is designed for rendering pixelart it may not be suitable for bigger images.
